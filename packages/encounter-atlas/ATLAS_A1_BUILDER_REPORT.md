Selection, Source/technical expansion, view changes and rereads operate on derived data. Integrity compares the complete canonical saved-run/package/catalog input and validated run, not just visible cards.

## Plain language and source paths

Templates translate actual typed records. Belief statements use evidence labels matching the recorded holder/question/value; they never borrow world facts to invent a conclusion. Accepted/suspected/disputed map to Believes/Suspects/Conflicting evidence. Unsupported mappings retain Untranslated Encounter detail and exact raw data. Known concerns are interpretations of received conduct, not motive truth. Ownership/current holding never comes from earlier location evidence or a clerk's role.

Source shows the immediate communication/result/occurrence, the person's received fragments, cited earlier sources and exact record. Full developer source inspection is separately labeled. Repeated receipts are retained as receipts and explicitly not independent corroboration; repeated citations deduplicate. IDs, schema fields and raw values are behind Encounter details except when name disambiguation requires identity.

Final QA corrected a presentation-only source label: a player-received immediate communication could previously fall through to Earlier source citation when no full developer record was available. The final adapter uses the already-filtered AR0 message/receipt to label its speaker and During this run, while keeping the earlier payload opaque. A1-19 and final browser checks exercise both the receiving Collector and the publicly reported witness message. No Encounter/AR0 code changed.

## Known limits and tester attack surface

Bounded to the current M3/AR0 schema and supported saved-run/catalog pair. Descriptive prose remains trusted authored input, not independently certified story truth. Source paths are bounded citations, not a universal explanation engine. Earlier storage facts may outlive current custody; they remain explicitly separate. There is no arbitrary NPC audience, complete timeline, generalized location/inventory or write contract. Player-received view is an inspection filter, not encryption: full developer saves/examples contain author truth.

Tested on this Windows PC, Node 24/Python 3.12 and one in-app Chromium browser viewport. Cross-browser/mobile/accessibility certification and direct-file launch are unclaimed. Use the tested HTTP launcher; default-browser auto-open has a printed-URL fallback. The pre-existing IR3-25 limitation is retained.

The independent Tester should attack identity/source isolation, malformed references and replay, same-name ambiguity, human versus NPC state, hidden versus absent/unmodeled data, report versus direct evidence, current holding versus old evidence, repeated-source corroboration, unsupported mappings, escaped raw input and every Source/technical expansion's purity. Treat all builder assertions as untrusted and independently verify the frozen identity. Stop after A1.
