# Shared contract inventory — Stage 12

Documentation only, inspected against Stage 11 base 0d901173109984bcc1df116f8cca73bc6d2efc06. Package bytes and product acceptance are unchanged. Encounter governs gameplay interaction meaning. No cross-package importer or binding is implemented by this inventory.

Classification: **OBSERVED** = enforced/current package contract or recorded data; **PRIVATE** = package-owned detail, not a shared standard; **CANDIDATE** = a justified reference across a future boundary; **DEFERRED** = not sufficiently specified to implement. An observed local identifier can be a candidate reference without becoming a universal ID.

## Identity/hash and unresolved boundaries

SHA256 is not a single interchangeable reference: Encounter package digest hashes canonicalJson(content); A1 source digest hashes its enumerated execution-input records; curated tree digests hash sorted path/bytes/hash records; archive/file hashes cover encoded bytes; ZANT decodedRGBA_SHA256 covers decoded pixel buffers. Carry the method/scope with a reference. Current identities are in [fingerprints](../docs/provenance/source-fingerprints.json), [Stage 10 projection](../docs/provenance/stage10-cleanup-manifest.json) and [ZANT verifier](../packages/zant/C001_ZANT_GATE_A_R5/validation/verify_checkpoint.py).

No shared binding wire format, global map registry, cross-package transform, automatic actor-to-presentation inference, universal actor/part taxonomy or schema migration framework is justified for implementation now. Room Creator story/prop normalization can invalidate naive references. A ZANT acceptance lock is not a complete-character compatibility guarantee. These are deferred questions, not gaps filled by invented schemas.

See [accepted conventions and deferrals](SHARED_CONTRACT_DECISION.md), [boundary matrix](BOUNDARY_MATRIX.md) and [illustrative examples](COMPATIBILITY_EXAMPLES.md). Initial consolidation completion does not mean subsystem product completion.
