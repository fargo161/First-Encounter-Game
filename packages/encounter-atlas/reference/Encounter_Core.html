Using Encounter Core

Author the world

Open World ledger to add or remove topics, define goods and balances, and create information entries. Information belongs to a topic and records who currently knows it. The ledger is an authoring view, not the player's knowledge.

Ask, tell, or exchange

Ask requests the counterparty's shareable information on a topic. Tell sends a statement the player knows. Trade combines goods, money, and information on either side. A submitted proposal does not transfer anything: review and confirm the exact offer.

Choose a delivery

The 20 ordered BASED vibes pair Belligerence, Aggression, Sociability, Empathy, and Deception. Subtle, Nuanced, and Overt change the signal's salience. The facts and trade terms remain fixed. In this build, Nuanced is the measured middle setting, not a separate blending editor.

Keep knowledge separate from belief

A spoken or traded statement reaches the listener as hearsay. It is not automatically verified. Optional question keys let incompatible claims produce disputed beliefs. The player has no simulated belief or personality matrix.

Save your work

Local autosave is attempted after every change. Save session exports the current world, transcript, NPC state, and pending offer. Export world exports only the current ledger. Open file accepts either. Browser storage can be unavailable or cleared, so keep exported backups.

Start another encounter

New encounter resets the conversation and NPC reception while keeping current balances, inventories, and knowledge. It does not roll back completed trades. The optional neutral test data is separate from the empty starting world.

Keyboard: L opens the ledger when not typing. Ctrl/⌘ + Enter sends a valid message. Escape closes dialogs.
