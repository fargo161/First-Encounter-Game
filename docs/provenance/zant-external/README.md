# External ZANT authorities

EXTERNAL_AUTHORITIES.json binds seven intake ZIPs to exact names, sizes, SHA-256, external paths and purposes. It names accepted R4/failed R5 checkpoints, separates original/design from rebuilt/calibration/fit/research roles, and maps imported C001 references to exact intake hashes.

tree-manifests/ preserves all 13 original ZANT inventories byte-identically: 506 preserved current R5 files, 620 original source/research inputs and separate history/evidence trees. Import selects 165 maintained R5 files plus the existing packet manifest. Other 340 delivery/duplicate files stay external; the excluded existing bytecode cache is untouched.

intake-and-checkpoints/ preserves the original delivery index/manifest and selected checksum/handoff/integrity sidecars. Historical instructions are provenance, not current authorization.

The archive is a same-drive checkpoint, not an off-device backup. Current paths and former workspace relocation are in ../source-authority.json. No older Trapstar Git repo/history was used.
