Select the owner-effort/growth aim rather than treating all compounding as an exploit. Basic presentation exceptions alone are no funded recovery. B-N03/B-N04/B-N05.
3. **Skipped time and present reward comparison:** D08 must select what actually operates offscreen, which opportunities can be missed and which costs still accrue. Compare workers, owners and shadow trade over the same horizon without counting future enforcement. B-N03/B-N04/B-N05/B-N06.
4. **Concealed-revenue benefit:** D11's narrow option offers ordinary supported access/spending/mixing/concealment with no special reward; its bounded recipient option needs actual acquired report and decision basis/current constraints. Retained source alone is neither cost nor detection, and throughput cannot validate a lie. B-N02/B-N05/B-N08.

These are priorities for any future dependent claim, not new prerequisites to accepting this audit or already accepted KeyWrapping architecture.
