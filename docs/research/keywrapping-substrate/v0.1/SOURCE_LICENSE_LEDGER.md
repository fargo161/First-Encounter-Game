# Source and license ledger

**Version:** v0.1 · **Date checked:** 2026-10-22
**Status:** PROPOSED / NON-RUNTIME / NOT AN ACCEPTED SHARED CONTRACT
**Role:** Repository & Documentation Steward; primary-source license inspection for the approved documentation package.

This ledger distinguishes permission to consult a resource from permission to redistribute its text, data or code. It records the particular artifacts inspected; it does not grant a license to the Encounter repository, the owner-held KeyWrapping source pack, frozen assets or any future implementation. Publication remains held by owner decision OD-KW-04 in the [decision log](../../../design/keywrapping-substrate/v0.1/DECISION_LOG.md).

All donor research dates below mean **checked on 2026-10-22**, not donor publication dates. A pinned commit identifies inspected bytes, not a claim that the project remains maintained or that all repository subcomponents share one license.

## Intake and future-publication rules

1. Keep corpus files, ontology graphs, donor examples, source libraries, owner-held originals and personal local evidence paths out of the package. Selected VN metadata and the retained licensing notice are the declared exception to the no-data-copy approach.
2. If new copied/adapted content is proposed, identify the exact source artifact, snapshot, copied scope, intended destination, changes and required attribution before inclusion. Record unresolved permission separately from technical usefulness.
3. Preserve inherited component licenses. A transformed FrameNet/VerbNet dataset inside Framester is not relicensed merely by the project's CC BY statement. A downloadable or publicly visible resource is not automatically cleared for redistribution.
4. Public GitHub metadata conflicts with private-repository prose. Treat any later push as potentially public; no push/publication is authorized. Owner acceptance of this research strategy does not clear unsupplied data or change repository visibility.
5. Recheck pins and exact license obligations if the content changes before a later authorized publication. Do not silently switch versions or import new donor releases while retaining this ledger's checked date.

Open rights questions: original FrameNet 1.7 release notice; any actual Framester component payload proposed for later reuse; exact dependency notices for a later EN/FA code intake; source-specific notices for any future copied W3C/JSON Schema material. None blocks the present citation-and-original-analysis scope.
