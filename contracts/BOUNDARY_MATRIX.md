# Minimal boundary matrix — Stage 12

This is an accepted documentation-level ownership boundary, not a runtime interface. Owners are observed from canonical contracts and the existing architectural direction; cross-system consumers below are permitted future consumers, unless an existing Atlas→Encounter reference is stated. No new connection or mutation path is implemented.

Reference forms are descriptive logical tuples, not a serialized schema or new ID grammar. Qualify local IDs by their owning subsystem and exact content/artifact identity; preserve the original ID and native version rules. Source evidence uses the E/R/Z finding labels in [the inventory](SHARED_CONTRACT_INVENTORY.md).

The boundary convention permits an explicitly authored reference; it does not assert that any illustrative mapping already exists. Exact binding serialization, lifecycle/remapping policy and engine/world transforms are deferred in [the decision](SHARED_CONTRACT_DECISION.md). Unknown-field preservation applies only where the owning package currently promises it.
