# Updated documentary proof set for later audit

**Date:** 2026-10-23, America/New_York  
**Status:** PHASE 4 PROPOSAL / FOURTEEN CHALLENGE GROUPS / NOT RUN

The nine [Phase 3 groups](../phase-3/MINIMUM_PROOF_SCENARIOS.md) were sufficient to index the original fifteen cases, but several hid independent distinctions in one large row. They were not sufficient as a separately assessable challenge specification. This revision isolates fourteen groups, retains every inherited case and adds underexposed role boundaries. This is design of future proof questions, **not execution of Phase 5 conservation, adversarial/sealing audit, play test or cold testing**.

Use the unchanged Phase 3 numerical store-warehouse-household loop as the documentary common target. Its stipulated relationships remain illustrative, not an executed baseline or a supported runtime. Extend only with separately stated opening facts and selected terms. Independent counterexamples below need not all inhabit one giant fixture. No named customer per aggregate sale, per-note identity or national supply simulation is required.

## Evidence required from a later authorized demonstration

Each subcase must separately state opening positions/relations, actual occurrence/effect scope, supplied terms/authority, credited scope, accounts/assertions, recipient-specific eligible acquired context, aggregate coverage/exclusions and finite support envelope. Specify expected and deliberately unavailable answers; distinguish conditional rights/outcome expectations from unconditional separations. A before/after snapshot alone may conceal duplicate performance, false record authority or lost history.

No rule/contract gap is filled with a new API or fabricated runtime semantics. A case without a selected title, policy, outcome or authority basis must label that result unresolved. Actual executable evidence, same-occurrence/save-reload guarantees and capacity limits require later authorized support. No number of documentary groups proves exhaustive composition.
