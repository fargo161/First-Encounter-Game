# Authorized foundation scope

Stage 0 records the settled repository, architecture, storage and status decisions.

Stage 1 preserves selected current editable trees, required original-source collections, R1-R4 ZANT history, relevant checkpoint packages, independent reviews and intake packages. All 6722 selected files and their copies were hashed; sizes/mtimes and selected directory membership were rechecked. This is a local checkpoint on the same physical drive.

Stage 2 establishes source authority, exact package identities, source fingerprints, independent evidence references, known defects, dependencies and owner disposition without importing source bodies.

Stage 3 creates a fresh local main branch, documentation/metadata/placeholder foundation, initial independent commit and a private GitHub remote. Successful publication is independently evidenced by the external completion report and remote branch SHA; do not infer it solely from this planned scope document.

The archive intentionally excludes unrelated projects, legacy Trapstar repositories and unnecessary repeated scratch/regression trees. Existing originals were not deleted or reorganized. No source build, behavioral test, repair, normalization, shared-contract implementation, CI workflow, Unity project or LFS conversion was run.
