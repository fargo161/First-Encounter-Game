## I. Proposed action-mining plan

Attempt all 66 words against pinned VerbNet first, supplement gaps with FrameNet and use Framester as an alignment aid. Each proposed sense should carry roles/restrictions, source evidence, REQUEST/OFFER/REMARK behavior, preconditions, effects, execution support, performative validity, examples, confidence and unresolved gaps.

Likely starting mappings included Give/Lend/Borrow/Pay/Go/Make/Destroy. Strong ambiguity included Take/Keep/Return/Share/Change/Break/Show/Hide/Open/Release. Performatives included Accept/Refuse/Promise/Allow/Forbid/Cancel/Withdraw/Forgive. Predicate candidates included TRUSTS/FEARS/NEEDS/BELIEVES. Near-duplicate comparisons included Accept/Agree; Refuse/Disagree/Oppose/Deny; Tell/Explain/Reveal; Help/Support; Give/Pay. Linguistic coverage must not imply a supported Encounter world capability.
