## Blocking defect M3-D01 — HIGH

**Fully transparent notice falsely authorizes collection-service closure.**

Location: `src/m3/ui.mjs:27–30`, `acknowledgeVisibleNotice`; propagation through `ui.mjs:73`, `engine.mjs:167`, `policy.mjs:12` and `engine.mjs:151–156`.

The guard checks `hidden`, computed `visibility`/`display`, rectangle height and vertical viewport containment. It does not check opacity. A notice with `opacity: 0` has a nonzero, fully onscreen rectangle, so the guard calls `markNoticeDisplayed`. The command then commits `notice.displayed: true`, selects `service_closure`, and performs one physical service-close result. No missing-preview defect is recorded.
